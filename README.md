## 🚀 About the Project

This is a modern, performance-driven personal portfolio designed and engineered from scratch. It features a unique **Cosmic UI/UX Design System**, combining abstract glassmorphism, floating micro-animations, and dynamic visual layouts to highlight my journey as a Software Engineer and Cloud Architect.

## ✨ Key Features

- 🎨 **Dynamic Cosmetic System:** Custom CSS configurations for glowing accents and abstract particle backgrounds.
- 📱 **Fully Responsive:** Meticulously crafted using Tailwind CSS to scale flawlessly from ultra-wide 4K monitors down to mobile viewports.
- 📬 **Live Contact System:** Integrated with **EmailJS** for functional client-side form submissions natively via React.
- 🎬 **Micro-Interactions:** Smooth UI transitioning utilizing **Framer Motion** algorithms (3D card carousels, slide-in delays).
- 🌓 **Theme Toggle:** Context-aware automated Light/Dark mode toggling.
